# Compare

## 1. Корректность решения

Функции `mergesort(nums)` и `quicksort(nums)` возвращают новый список по возрастанию. Повторы сохраняются. [Решение](compare.py)

## 2. Объяснение решения

Пустой список и список из одного числа уже отсортированы. Более длинный список mergesort делит пополам и сортирует каждую половину рекурсивно. При слиянии достаточно сравнивать первые числа двух отсортированных половин. Меньшее идёт в ответ, а когда одна половина заканчивается, остаётся дописать другую.

Quicksort берёт последнее число за опорное и делит список на три части. Слева оказываются числа меньше опорного, посередине равные ему, справа большие. Средняя часть уже на месте. Из двух крайних частей меньшую сортируем рекурсивно, а к большей переходим в цикле.

Декоратор `timed` считывает часы до и после вызова функции. Он возвращает результат и разницу показаний в наносекундах. Оборачиваем только внешний вызов, чтобы получить время всей сортировки.

## 3. Оценка сложности

- **Mergesort.** Время O(n log n). На каждом уровне сливаем суммарно n элементов, уровней O(log n). Срезы и результат слияния занимают в сумме O(n) памяти одновременно.
- **Quicksort.** На случайной перестановке время в среднем O(n log n). Если опорное каждый раз самое большое, остаются части длины n − 1, n − 2 и так далее. Тогда время O(n²). Стек занимает O(log n), так как рекурсивно сортируется меньшая часть. Вместе с копией списка память O(n).

## 4. Визуализация работы алгоритма

Вход `[4, 1, 3, 1, 2]`. Mergesort делит его на `[4, 1]` и `[3, 1, 2]`. Затем выполняются слияния в таком порядке.

```text
[4] + [1]          → [1, 4]
[1] + [2]          → [1, 2]
[3] + [1, 2]       → [1, 2, 3]
[1, 4] + [1, 2, 3] → [1, 1, 2, 3, 4]
```

Quicksort на том же входе обрабатывает три отрезка. Между чертами стоит блок равных опорному.

```text
[4, 1, 3, 1, 2]  →  [1, 1] | [2]    | [3, 4]
[3, 4]           →  [3]    | [4]    | []
[1, 1]           →  []     | [1, 1] | []
```

## 5. Тесты

Обе сортировки проверяются на пустом списке, одном элементе, смеси чисел с повторами, обратном порядке, длинном возрастающем списке и одинаковых числах. В каждом случае исходный список должен сохраниться. Для декоратора проверяем и результат функции, и время между двумя заданными показаниями часов. [Тесты](test_compare.py)

Для сравнения времени взяты два списка по 2 000 чисел. Декоратор `timed` замеряет один вызов сортировки. В таблице приведена медиана пяти запусков в миллисекундах.

| Вход | Mergesort, мс | Quicksort, мс |
| --- | ---: | ---: |
| Числа от 0 до 1999 по возрастанию | 0,875 | 62,517 |
| Все числа равны 7 | 0,860 | 0,038 |

В первом случае опорным всегда оказывается максимум, и quicksort сокращает отрезок всего на один элемент. Во втором случае все числа попадают в среднюю часть за один проход. Mergesort в обоих случаях выполняет одинаковое число слияний. Повторить замеры можно командой `python3 compare/compare.py` из папки `homework_6`.
