# Iterative

## 1. Корректность решения

Обе функции возвращают отсортированную копию списка. В `mergesort` слияния выполняются в цикле, а в `quicksort` границы отрезков хранятся в стеке. [Решение](iterative.py)

## 2. Объяснение решения

Mergesort начинает с блоков длины 1. Сначала сливаются соседние элементы, затем пары, четвёрки и так далее. После каждого прохода длина отсортированного блока удваивается. Если в конце остался блок без пары, он целиком переходит в буфер.

Quicksort берёт опорное число из середины отрезка. Два индекса идут навстречу друг другу. Если слева нашли число ≥ опорного, а справа число ≤ опорного, меняем их местами и сдвигаем оба индекса. Так проход продолжается и при равенстве чисел. После разбиения в левой части все числа не больше опорного, а в правой не меньше. В стек кладём каждый отрезок, в котором осталось хотя бы два элемента. Когда стек пуст, список отсортирован.

## 3. Оценка сложности

- **Mergesort.** Время O(n log n). За проход один раз переписываем n элементов, а ширина блока каждый раз удваивается. Копия списка и буфер занимают O(n) памяти.
- **Quicksort.** Разбиение линейно по длине отрезка. На случайной перестановке время в среднем O(n log n), при последовательных разбиениях на сильно неравные части оно может достигать O(n²). Большую часть кладём в стек первой, поэтому следующей разбираем меньшую. Стек занимает O(log n), а вместе с копией списка память O(n).

## 4. Визуализация работы алгоритма

Вход `[6, 2, 5, 3, 1, 4, 3]`. У последней тройки в первом проходе mergesort нет пары.

| Длина блоков до слияния | Блоки после прохода |
| ---: | --- |
| 1 | `[2, 6] [3, 5] [1, 4] [3]` |
| 2 | `[2, 3, 5, 6] [1, 3, 4]` |
| 4 | `[1, 2, 3, 3, 4, 5, 6]` |

Quicksort на том же входе. Границы отрезков включены, вершина стека справа.

| Отрезок | Опорное | Список после разбиения | Стек |
| --- | ---: | --- | --- |
| 0–6 | 3 | `[3, 2, 1, 3, 5, 4, 6]` | `[(0, 2), (4, 6)]` |
| 4–6 | 4 | `[3, 2, 1, 3, 4, 5, 6]` | `[(0, 2), (5, 6)]` |
| 5–6 | 5 | `[3, 2, 1, 3, 4, 5, 6]` | `[(0, 2)]` |
| 0–2 | 2 | `[1, 2, 3, 3, 4, 5, 6]` | `[]` |

## 5. Тесты

Для обеих сортировок проверяются пустой список, один элемент, повторы, прямой и обратный порядок. На семи элементах у последнего блока в первом проходе mergesort нет пары, а на восьми все блоки сливаются попарно до конца. Каждый тест также проверяет, что функция вернула новый список.
